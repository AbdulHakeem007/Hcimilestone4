# Security Policy

## Supported versions
Security fixes are applied on the latest `main` branch.

## Reporting a vulnerability
Please **do not** open a public issue for security-sensitive findings.

Report privately via GitHub Security Advisories on this repository, or contact the maintainer through their GitHub profile.

Include:
- affected component / endpoint
- reproduction steps
- impact assessment
- any suggested fix

You should receive an acknowledgement within a few business days.
